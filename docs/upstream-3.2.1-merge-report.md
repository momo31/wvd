## 주요 구현과 기존 동작 보존

- `config_model.py`를 GUI와 headless의 공통 설정 계층으로 분리했다. 언어 키를 한 번 이전하고 지정 설정 경로, 알려지지 않은 키, 다른 작업 설정을 보존한다. 자동 인계에서는 대상 작업 설정을 다시 읽되 저장된 선택을 변경하지 않는다. GENERAL의 언어·Telegram 값은 작업 섹션으로 덮어쓰지 않는다.
- 컨트롤러는 요청 큐와 예약 작업을 소유한다. WebView는 메인 스레드에서 실행하며 창 닫기 후 새 요청을 막고 워커·원격 서비스·다운로드를 제한 시간 내 정리한다. 이전 실행·이전 워커의 이벤트와 중복 인계를 걸러내고, 정지 요청이 인계보다 우선한다.

## 자산과 현장 검증의 한계

## 실행 중 판단과 영향

1. 호스트의 native worktree 생성이 불완전한 상위 폴더에서 실패해 실제 저장소에서 Git worktree를 만들었다. 호스트 작업본 UI가 이 디렉터리를 직접 관리하지 않으므로 경로를 명시해 사용해야 한다.
2. 저장소의 커밋 금지와 계획의 원본 보존 지침을 우선해 커밋 대신 체크포인트·diff·기록을 남겼다. 결과는 미커밋 기능 이식이며 Git 병합 이력이 생기지 않는다. 작업본은 그대로 보존한다.
3. 삭제/알 수 없는 목표는 설정을 읽을 때 보존하고 공통 실행 시작 경계에서 거부했다. 옛 설정을 편집할 수 있지만 실행 경계 검증이 빠진 경로가 생기면 잘못된 목표가 실행될 위험이 있다. 공통 시작 경계 회귀 테스트로 현재 경로를 확인했다.
4. 지정 설정 파일을 명시적으로 읽는 기존 테스트는 한 번의 언어 키 이전을 허용하도록 갱신했다. 명시적 설정 로드 시 해당 파일이 한 번 변경될 수 있으며, 로케일만 읽는 경로는 저장하지 않는다. 기본 설정 파일 불변을 함께 검증했다.
5. 중국어 게임의 누락 자산 8종 때문에 로컬 안전 판정을 제거하거나 영어 이미지로 대체하지 않았다. 따라서 중국어 게임 자동화는 실제 대응 캡처를 추가하기 전까지 사용할 수 없다.
6. 커밋이 없어 공식 검토 패키지 생성기의 HEAD 비교가 빈 범위를 반환했다. 보존한 원본 대비 전체 파일 diff와 목록으로 독립 검토를 수행했다. 검토 범위는 파일 내용이며 Git 병합 이력은 검증하지 않는다.
